# Bundled subtitle font

Noto Sans CJK SC Regular, unmodified OpenType font from the official Noto CJK repository:

https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf

Upstream Git blob: `dc15562470b4f842321894787a0d066879ccff8b`.
Size: 16,437,364 bytes. Distributed under the accompanying `OFL.txt` (SIL Open Font License 1.1). Copyright notices are also embedded in the font metadata.

The font is loaded from the extension package, never from a CDN at playback time. It provides shared Latin and CJK glyphs across operating systems. Scripts outside its coverage use the system fallback; native video fullscreen and picture-in-picture use browser-controlled typography.

To update, replace the font with the upstream release, retain its license, record its Git blob and size here, and rerun the subtitle preview and regression tests.
