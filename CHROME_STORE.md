# Chrome Web Store Release Notes

Use this as the submission checklist for the Chrome Web Store listing.

## Listing Summary

Echo360 Online Subtitle Translator helps users load translated subtitles on Echo360 recorded lectures.

Core user-facing behavior:

- Detects available Echo360 VTT subtitle sources on supported lecture pages.
- Translates subtitles with the selected provider.
- Displays translated or bilingual subtitles in the Echo360 player.
- Caches the latest translated subtitle locally for quicker reloads.

## Recommended Short Description

Translate Echo360 lecture subtitles and display them on recorded videos.

## Permission Justification

- `storage`: Saves extension settings, optional API key, subtitle display preferences, and local subtitle cache.
- `https://translate.googleapis.com/*`: Google Translate provider.
- `https://api.deepseek.com/*`: DeepSeek provider.
- `https://api.openai.com/*`: OpenAI provider.
- `https://generativelanguage.googleapis.com/*`: Gemini provider.
- `https://api-free.deepl.com/*`, `https://api.deepl.com/*`: DeepL provider.
- Echo360 and Canvas host permissions: Required to find subtitle sources, observe Echo360 video state, and attach translated subtitle tracks on supported course pages.

Generate the Chrome Web Store package with `npm run build:store`. The store build removes `localhost` / `127.0.0.1` permissions and hides the local backend UI. Local backend support is available only in the development build generated by `npm run build:dev`.

## Privacy Disclosure

Privacy policy file: `PRIVACY.md`

Suggested disclosure:

This extension stores settings and optional API keys locally in Chrome storage. Subtitle text is sent only to the translation provider selected by the user. The Chrome Web Store build does not operate a remote server or local backend feature that collects API keys, subtitles, account data, or browsing history.

## Final Manual Checks

- Reload the unpacked extension from `chrome://extensions`.
- Confirm the default provider is `Google Translate` for free first-run use.
- Confirm Google Translate works without an API key and is described as quick/free trial use, not the quality-focused recommendation.
- Confirm DeepSeek/OpenAI/Gemini/DeepL are described as better-quality AI/API options and show that an API key is required.
- Confirm options page saves provider and target language.
- Confirm the store build does not show the local backend option.
- Confirm `dist/extension-store/manifest.json` does not include `localhost` or `127.0.0.1`.
- Confirm translated subtitles can be loaded, hidden, shown, resized, and reloaded from cache.
- Confirm the Chrome Web Store listing links to a public privacy policy URL.
