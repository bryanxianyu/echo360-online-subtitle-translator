# 统一字幕渲染维护说明

## 模块边界

- `subtitle_timeline.js`：解析 VTT，查询当前时间内的全部 cue；支持重叠、短时间码和向后跳转。所有 cue 内容先转为纯文本，再通过 `textContent` 显示。
- `subtitle_layout.js`：计算视频画面与可视窗口、裁切祖先的交集；全屏时在全屏边界停止向上查找。字号、边距的数值只在这里调整。
- `subtitle_overlay.js`：Shadow DOM 样式、双语排版、字体、播放事件、原生模式回退和用户提示。背景色、透明度、圆角只在这里调整。
- `renderer.js`：沿用现有字幕源/视频匹配和增量预览流程，默认调用覆盖层。历史 `useNativeSubtitles=true` 现在代表统一覆盖层；false 仍代表原生 CC Beta。

普通播放与容器全屏不按 UA 或 macOS/Windows 版本分支。普通播放使用接近画面底部的固定比例边距，容器全屏使用较大的原生字幕风格边距；Echo360 控制栏显示或隐藏不会再让字幕跳动。视频时间是唯一的同步时钟；播放中用动画帧查询当前 cue（并节流几何测量），暂停/拖动/增量更新立即刷新。长句在同一个字幕块中向上增长。极小的可视区域无法容纳无限文字，字幕块会限制在可用区域内。

原生 CC 开关完全由用户控制，扩展不会点击按钮，也不会修改原生 TextTrack 的显示状态。原生 CC 与翻译覆盖层可以同时显示，重叠会明确提示用户关闭 Echo360 原生 CC；卸载扩展不会改变用户最后的 CC 选择。不能通过宽泛的页面文本搜索删除原生字幕 DOM。

## 字体与回退

随扩展打包 Noto Sans CJK SC Regular（约 16 MB，OFL 1.1），运行时不请求 CDN。来源、版本和许可证在 `extension/fonts/`。系统缺省字体只作为加载失败或缺失字形时的后备；字体栅格化差异仍存在。

视频元素自身全屏、`webkitDisplayingFullscreen`、原生视频画中画无法保证显示普通 HTML。此时保留一个原生字幕 track，使用从底部向上排列的 `line:-3`，退出后释放 track 和 blob URL。原生模式的样式及画中画字幕支持由浏览器决定，不纳入跨平台统一外观承诺。没有强行退出系统全屏或替换 Echo360 播放器。

## 本地可重复验收

运行 `python3 -m http.server 8877 --bind 127.0.0.1`，打开 `http://127.0.0.1:8877/tests/fixtures/subtitle-preview.html`。页面直接加载生产字幕模块，可验证单语、双语、原文在上、长句、三档字号、播放器裁切、容器全屏和隐藏。预览不调用翻译 API，视频是静态占位，真实播放与原生视频全屏需要另行验证。

运行 `npm test` 与 `npm run build`。`tests/unit/subtitle_overlay.test.js` 验证时间轴、文本安全、显示状态、增量更新、视频切换、全屏/画中画切换及资源清理。

发布前在 macOS 的 Safari/Chrome 和 Windows 的 Chrome/Edge 运行相同用例：

| 场景 | 通过标准 |
| --- | --- |
| 同一分辨率的单语/双语 | 背景、字形、行高和排序一致；允许抗锯齿细微差异 |
| 页面缩放 80% / 100% / 125% / 150% | 字幕在可见视频区域内，无底部裁切 |
| 窗口缩放、打开 Transcript、滚动 | 位置随真实画面变化，无遮挡和旧位置残留 |
| 长中文、英文、RTL 文字、多行/重叠 cue | 正确换行、方向、顺序与结束时间 |
| 暂停、前后拖动、0.5x / 1x / 2x | 当前 cue 与视频时间一致，无定时器累计漂移 |
| 增量翻译、修改设置、取消后重试 | 更新当前字幕，不重复挂载或恢复已取消结果 |
| 容器全屏及退出 | 字幕处于全屏层内，退出恢复正常位置 |
| 原生视频全屏、PiP | 走 track 回退并记录浏览器实际支持情况 |
| 视频更换、字幕关闭、切换 Beta | 保留原字幕选择，移除旧层/监听器/动画帧/blob URL |

自动化 DOM 测试不等于真实 OS/浏览器验证。更新系统后，先用此预览区分独立字幕布局问题与 Echo360 页面集成问题。
